# 校园美食平台接口文档（前后端共用）

地址：`http://localhost:8080`（只打网关，不要写 8081–8085）

按**模块**分章（登录、个人中心、美食、社交、拼单、商家、订单、管理）。每条接口标题标 **已实现** 或 **还没做**。

已实现的：**路径、字段和现在的 Java Controller 一样**。还没做的：前端先不要调（会 404）；以后补也用同样的返回方式，不要再包一层 `data`。

---

## 怎么读

**成功：** HTTP 200，body 就是业务 JSON，没有 `{ "code": 0, "data": ... }`。  
**失败：** HTTP 400，`{ "code": 400, "message": "原因" }`，把 `message` 弹给用户。  
**没登录：** HTTP 401，`{ "code": 401, "message": "未登录或 Token 缺失" }`，清 token，跳登录页。  
**服务器挂了：** HTTP 500，提示「服务繁忙，请稍后重试」。

登录后每个请求加头：`Authorization: Bearer <token>`

分页（页码从 1 开始）：

```json
{ "total": 100, "page": 1, "size": 10, "list": [] }
```

`roleId`：`1` 学生　`2` 商家　`3` 管理员

金额一般是数字（如 `18.0`）。时间一般是 `"2026-11-10T21:00:00"`。主键字段名跟返回 JSON 走：用户资料是 `id`，不是 `userId`。

`void` 接口成功时 body 为空。商家 `insert/update/delete` 成功体是数字（影响行数）。

前端开发可把 `/api` 代理到 `8080`，代码里写 `/auth/login` 这种路径。TypeScript 见 `docs/frontend/types.ts`。

**不要按旧稿去做这些事：** 不要改成 `{code,message,data}`；不要把 `/social/sendFriendRequest` 改成 `/social/friend-requests`；不要把下单改成购物车 `cartItemIds` 再单独支付；不要把金额改成字符串。识图是课设可选项。分享到微信/QQ 前端复制详情链接即可。系统监控答辩看 Eureka `http://localhost:8761`。

## 1 登录注册

### 1.1 注册　已实现　不用登录

```
POST /auth/register
```

请求：手机号、邮箱至少填一个。现在**不要传** `code`（验证码还没接）。

```json
{
  "phone": "13800138000",
  "email": "",
  "password": "abc12345",
  "nickname": "小杨"
}
```

返回：

```json
{
  "id": 1,
  "nickname": "小杨",
  "roleId": 1
}
```

注册成功没有 token，再调一次登录。

### 1.2 登录　已实现　不用登录

```
POST /auth/login
```

`username` 填手机号或邮箱。

```json
{
  "username": "13800138000",
  "password": "abc12345"
}
```

返回：

```json
{
  "id": 1,
  "nickname": "小杨",
  "roleId": 1,
  "token": "eyJhbGciOiJIUzI1NiJ9..."
}
```

前端存 `token`、`id`、`nickname`、`roleId`。退出：清本地 token，没有退出接口。

### 1.3 发验证码　还没做

任务书 7.1。

```
POST /auth/code
```

```json
{ "target": "13800138000", "targetType": "PHONE", "scene": "REGISTER" }
```

`targetType`：`PHONE` / `EMAIL`。`scene`：`REGISTER` / `RESET`。

```json
{ "expireIn": 300, "resendAfter": 60 }
```

验证码接上之后，注册请求再加 `"code": "123456"`。没接之前不要传 `code`。

### 1.4 微信 / QQ 登录　还没做

任务书 4.1，可以做假授权页。

```
GET /auth/oauth/WECHAT/url
```

返回 `{ "url": "https://..." }`。用户授权完：

```
POST /auth/oauth/WECHAT/callback
```

```json
{ "code": "第三方回来的code" }
```

返回和登录一样：`id` `nickname` `roleId` `token`。`WECHAT` 可换成 `QQ`。

## 7 订单

配送：`1` 到店自提　`2` 配送到寝。

现在没有购物车接口。详情页直接下单，body 用 `items`。MOCK 付完直接 `PAID`，没有单独的支付接口。
