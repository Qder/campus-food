## 本地运行

1. MySQL 建库 `campus_food` 并执行项目 SQL 脚本（如有）。
2. 修改 `src/main/resources/application.yml` 中的数据库账号密码。
3. 启动 `com.campus.food.campusfood.CampusFoodApplication`。
4. 默认接口地址：`http://localhost:8080`。
